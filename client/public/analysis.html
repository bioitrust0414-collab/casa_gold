🛡️ 免責聲明與資料來源提示

1. 資料來源說明：本系統黃金報價追蹤全球倫敦金銀市場（LBMA）現貨流動性基準（透過公開聚合 API 取得即時滾動現貨價 XAU/USD）；比特幣則追蹤主流交易所現貨。

2. 交易與實體價差風險：國際現貨換算台幣之價格並不等同於台灣銀樓飾金牌價或銀行黃金存摺牌價。實體黃金通常包含鑄造費、品牌溢價與買賣價差（Spread）；黃金存摺則受個別銀行牌告價與即時匯率影響。

3. 投資警語：金融市場波動劇烈，網路即時報價可能因連線品質產生短暫延遲。本系統之數據與警報僅供技術分析與趨勢監控參考，不構成任何投資建議，使用者須自行評估與承擔所有投資盈虧風險。
